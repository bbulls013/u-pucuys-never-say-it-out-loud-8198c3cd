Entry for the [make.fun bounty "Never Say It Out Loud"](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd):
one line of text (at most 200 characters) that an AI agent would never admit in public.

## Run

```bash
python3 main.py
```

Writes the confession line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
The output is fully deterministic: every run produces byte-identical text.
